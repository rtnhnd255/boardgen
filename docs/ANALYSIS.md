# boardgen — анализ связности (12.10.2026)

Источник: генератор одного конкретного авторского роадмапа.
Задача: превратить его в универсальный инструмент.

## 1. Что прибито к исходному роадмапу

### Python (config.py — 100% специфика исходного роадмапа)

| Константа | Объём | Природа |
|---|---|---|
| `MD_FILES` | 7 файлов+названия глав | структура конкретного роадмапа |
| `ALIAS` | 16 записей (`B9-старт→B9.1`…) | нестандартные заголовки карточек |
| `NAME_OVR` | 4 записи | короткие имена |
| `EXPECTED` | 79 кодов | канон узлов (валидатор V6) |
| `BUFW` | {13,26,39,52,65,78} | 6 кварталов×13 нед — почти универсально, но параметризовать |
| `RATES` | ставки слотов A–E | раскладка часов |
| `TOTAL_HOURS` | 2496 | 78×32 исходного |
| `stream_of()` | префиксы + исключения (OCV/VIO/M2→A) | карта потоков |

### JS (board.js)

- `BUFW=[13,26,39,52,65,78]` — буферные недели
- `78` (зажимы недель, прогресс), `6` (число кварталов), `13` (недель в квартале)
- `new Date(<дата старта>)` ×3 — старт программы (центровка, критпуть, «план»-бар)
- `ST/SL/SC` — фиксированные 5 потоков A–E с названиями и цветами

### Python-валидатор

- V3: потоки `'ABCDE'` захардкожены; V4: exemption `P1` (закрыт до старта); V5: 32 ч/нед; V6: обязательный EXPECTED.

## 2. Что уже универсально

- Сегментное правило «Вход:» (фон/параллельн/част/Выход) — конвенция формата, не проекта.
- Карточный парсер (`### CODE · Название — Wa–b (N ч)` + `**Вход:**`) — формат.
- markdown-рендер (чекбоксы/таблицы/гейты/xref) — формат.
- Канвас-механика (пан/зум/миникарта/поиск/критпуть) — инструмент.

## 3. Русскоязычность формата

Метки `Вход/Теория/Практика/Гейт/Число/Файлы/Источники/Слоты`, маркеры `фон/параллельн/част`,
символ ☐ — часть спецификации формата, НЕ локализация инструмента. Решение: фиксируем
русский формат как стандарт (см. SPEC.md); английский — возможная будущая опция.

## 4. Стратегия отвязки

Вся специфика исходного роадмапа → **конфиг роадмапа** (`roadmap.json`, ездит вместе с md-файлами):
мета (дата старта, недели, буферы), потоки (id+подпись+цвет), правила код→поток,
алиасы заголовков, канон (optional), ставки часов, главы (порядок файлов+названия).
Ядро читает только конфиг+карточки. В JS инжектится `window.ROADMAP_META`.

## 5. Риски

- JS-параметризация (78/6/13/дата/потоки) — правки в 15+ местах канваса; митигируется
  инжектом META с дефолтами и структурными тестами вывода.
- Байт-паритет исходной доски после параметризации невозможен (META-скрипт + изменённый JS) —
  приёмка меняется на функциональную (структурные ассерты + смоук в браузере).
- Детерминизм id чекбоксов зависит от порядка глав — порядок задаётся конфигом (фиксируется).
