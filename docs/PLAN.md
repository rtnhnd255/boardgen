# boardgen — план выделения в standalone-инструмент

Вход: ANALYSIS.md. Выход: универсальный генератор досок из markdown-роадмапов.

## Этапы

| # | Этап | Проверка |
|---|---|---|
| 1 | Документы: ANALYSIS / PLAN / SPEC(формат) | — |
| 2 | Каркас репо: пакет `boardgen/` + CLI (`argparse`) | `python3 -m boardgen --help` |
| 3 | `RoadmapConfig`: загрузка json + дефолты; вся специфика исходного роадмапа — в конфиг | юнит-тесты конфига |
| 4 | Параметризация ядра: cards/graph/validate/budget принимают config | тесты на фикстурах |
| 5 | JS-META: инжект `ROADMAP_META`, вынос 78/6/13/даты/потоков из board.js | структурные ассерты вывода |
| 6 | CLI: `build`/`check`, `--config`, `--input`×N (порядок важен), `--output` | смоук на examples/mini |
| 7 | Тесты: юниты переносятся (конфиг-фикстуры), интеграция — на мини-примере + golden | unittest зелёный |
| 8 | Обёртка исходного роадмапа: `roadmap.json` + тонкий `gen.py` → CLI; пересборка | доска не деградировала |
| 9 | README / AGENTS.md / skills ×3 (opencode, claude, codex) | установка в системные локации |
| 10 | Журналы исходного проекта; бэкап доски до пересборки | — |

## CLI-контракт

```
python3 -m boardgen build --config roadmap.json [--output out.html]
python3 -m boardgen check --config roadmap.json
python3 -m boardgen build --input a.md --input b.md --output out.html   # без конфига: дефолты
```

- `--input` повторяемый; порядок = порядок глав = детерминизм id чекбоксов.
- `--config` даёт всё: главы (порядок+названия), мета, потоки, алиасы, канон.
- Выход: один самодостаточный HTML (file://).

## Дальние фичи (п.7 исходной задачи — бэклог)

1. **Экспорт состояния**: кнопка «выгрузить/загрузить прогресс» (JSON-файл) — перенос
   между машинами, архив снапшотов.
2. **Интеграция с Git**: pre-commit hook — `boardgen check` + пересборка доски в CI.
3. **Тёмная тема** + сохранение предпочтений в localStorage.
4. **Мультивью**: свёртка по потокам/кварталам, режим «только критический путь».
5. **Burn-down по числам**: прогресс «Стены чисел» (метрики) рядом с чекбоксами.
6. **Импорт из Mermaid/Graphviz**: конвертер gantt/dot → карточный формат.
7. **Английские метки** как опция формата (`labels: {input: "Prereq", …}`).
8. **PDF-экспорт** через headless-печать (Playwright) — квартальные «печатные листы».
9. **Серверный режим**: FastAPI-обёртка с раздельным localStorage по пользователю.
10. **Линта карточек**: `boardgen lint` — стиль карточек (часы в заголовке, ☐-формат,
    длины строк) сверх структурного валидатора.

## Риски и решения

- JS-правки вслепую → мини-пример + структурные тесты + смоук прод-доски вручную.
- Обратная совместимость исходного роадмапа → вся его специфика в `roadmap.json`, дефолты ядра нейтральны.
