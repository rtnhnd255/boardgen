# SPEC: формат роадмапа, совместимого с boardgen

boardgen визуализирует **карточный markdown-роадмап** как интерактивную доску
(канва-граф зависимостей + чек-листы + бюджет часов). Документ определяет формат.

## 1. Состав роадмапа

```
my-roadmap/
  roadmap.json      # конфиг (см. §6; может отсутствовать — тогда дефолты)
  00_CONSTITUTION.md # главы-файлы (имена любые; порядок задаётся конфигом/флагами)
  10_STAGE_1.md
  ...
```

Каждый md-файл = глава доски. Первый файл обычно «конституция» (обзор, гейты,
календарь) — для boardgen это просто глава.

## 2. Карточка блока

Карточка = секция `###` в любом md-файле. Формат заголовка:

```
### CODE · Название блока — W4–12 (45 ч)
```

- `CODE` — идентификатор: `Буква(+буквы)цифры(.цифра)?`, например `P2`, `B9.1`, `S13`,
  `CPP4`, `Ф1`. Первая буква/префикс определяет поток (через конфиг §6).
- `— W4–12` — недели жизни блока (дефис или en-dash; `W4` = одна неделя).
- `(45 ч)` — бюджет часов (необязательно; используется в таблице бюджета и валидаторе).
- Если блок живёт в двух главах (спилл-овер) — карточка повторяется; недели
  объединяются объединением (union), тело = первое вхождение. Повтор помечай
  `(финиш: W53–56)` в заголовке.

Стандарт полей (все необязательны структурно, но рекомендованы; валидатор может
требовать через конфиг):

```
**Вход:** P5, S8 (пояснение); (фон: B2 — для контекста); B4 (част. с W39+).
**Слоты:** Пн-3, Сб-4 …            # или «По неделям: W1 … W2 …»
**Теория (14 ч):** …                # '·'/'｜'-разделители не нужны
**Практика:** 1) шаг 2) шаг         # или '·'-список, или ol-список ниже
**Гейт (сб 09.01.2027):** ☐ пункт ☐ пункт
**Число:** ≥64 задач
**Файлы:** `folder/note`
**Источники:** Книга гл.1–3; course.example
```

### 2.1. «Вход:» — сегментное правило (ядро DAG)

Строка делится на `;`-сегменты; сегменты до слова «Выход» (регистронезависимо):

| Сегмент содержит | Класс | На канве |
|---|---|---|
| код(ы) без маркеров | **жёсткий вход** | сплошное ребро |
| `фон` или `параллельн` | мягкий вход | не рисуется |
| `част` (+ `WN+`) | частичный вход | пунктир + метка `WN+` |
| после «Выход:» | потребители | игнорируется |

Маркеры действуют на **весь `;`-сегмент**: частичный вход пиши отдельным сегментом
(`Вход: C2; A4 (част. с W18+)`, не через запятую). Токен = известный код блока (без `W`/`Q`/`G`-префиксов, точка на конце допускается).
Токен «формы кода», которого нет в реестре, в жёстком сегменте = **ошибка V1**
(ловим опечатки).

## 3. Чекбоксы и localStorage

- `☐` в **Гейт**/**любом** label → `<input>` с id `ck-{CODE}-{n}`; `n` — сквозной
  счётчик по порядку глав. **Порядок файлов менять нельзя** (валидатор канона
  + детерминизм id).
- Нумерованные пункты в **Теория/Практика** (`1) … 2) …`, `·`-списки, ol-после
  пустого Практики-лейбла) тоже становятся чекбоксами.
- Блок считается закрытым, когда прожаты все его чекбоксы (или вручную).

## 4. Спец-секции

- `### Буфер A — W12–13: …` — служебные секции без `CODE ·` игнорируются парсером.
- Заголовок `## G1 …` получает якорь `#gte-G1` (переход из буферной зоны канвы).
- ```` ``` ````-блоки пропускаются целиком.
- Таблицы markdown рендерятся как есть.

## 5. Нестандартные заголовки

Если заголовок не начинается с `CODE ·`, задай алиас в конфиге:
`"alias": {"B9-старт": "B9.1"}` — префикс заголовка → канонический код.

## 6. roadmap.json

```json
{
  "start_date": "2027-01-03",          // неделя 1 начинается с этого воскресенья
  "total_weeks": 78,
  "buffer_weeks": [13, 26, 39, 52, 65, 78],   // жёлтые гейт-зоны
  "quarters_weeks": 13,                 // недель в квартале
  "total_hours": 2496,
  "max_hours_per_week": 32,
  "completed_codes": ["P1"],            // не проверяются на заезд (закрыты до старта)
  "chapters": [                         // порядок = порядок глав и id чекбоксов
    {"file": "00_CONSTITUTION.md", "title": "Конституция"},
    {"file": "10_Q1.md", "title": "Q1 · Фундамент"}
  ],
  "streams": {                          // id → подпись и цвет
    "A": {"label": "RT/Embedded", "color": "#1a365d"},
    "B": {"label": "Математика", "color": "#00838f"}
  },
  "code_to_stream": {
    "exact": {"OCV": "A", "M2": "A"},   // точные коды
    "prefix": {"P": "A", "S": "A", "CPP": "A", "B": "B", "Ф": "B",
               "C": "C", "D": "D", "E": "E"}   // длиннейший префикс побеждает
  },
  "alias": {"P1-ретро": "P1"},
  "name_overrides": {"P1": "P1 Rust I"},
  "expected": ["P1", "P2"],             // опционально: канон узлов (валидатор V6)
  "rates": {"A": 19, "B": 5},           // ч/нед для таблицы бюджета
  "page_title": "Мой роадмап",
  "ls_key": "my-roadmap",            // localStorage-ключ прогресса (уникальный на роадмап)
}
```

Дефолты (без ключа/без конфига): total_weeks 78, quarters_weeks 13, буферы —
концы кварталов, потоки A–E со стандартными подписями «Поток A…» и палитрой,
code_to_stream — точное соответствие первой буквы, max_hours_per_week 32,
канона нет (V6 отключён).

## 7. Валидатор (boardgen check)

| # | Правило |
|---|---|
| V1 | висячие входы; токены-«формы кодов» вне реестра в жёстких сегментах |
| V2 | циклы DAG |
| V3 | непрерывность каждого потока W1..total_weeks (без дыр) |
| V4 | жёсткий вход закрывается до старта блока (исключения: част., completed_codes) |
| V5 | часы > max_hours_per_week — ошибка; часы не указаны — предупреждение |
| V6 | (если задан expected) канон узлов 1:1 |
| V7 | статические ✅/✗ во «Вход:» |

Ошибки → nonzero exit + отчёт; сборка не пишет файл.

## 8. Доска (выход)

Один HTML: канва (пан/зум/миникарта/поиск/критпуть/скрытие закрытых/сброс-undo),
карточки с чекбоксами (автосохранение localStorage, ключ из page_title),
буфер-зоны с переходом к гейтам, таблица бюджета, print-CSS. Внешняя зависимость —
только Google Fonts (офлайн-деградация на system-ui).
