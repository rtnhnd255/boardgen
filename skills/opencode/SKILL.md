# boardgen-roadmap

boardgen превращает набор markdown-глав с карточками блоков в самодостаточный
интерактивный HTML: канва-граф зависимостей (пан/зум/миникарта/поиск/критический
путь), чекбоксы с автосохранением прогресса (localStorage), буферные гейт-зоны,
таблица бюджета часов, print-CSS.

Инструмент: `~/rofls/boardgen` (полная спецификация формата: `docs/SPEC.md`).

## Формат карточки (ядро)

```markdown
### CODE · Название блока — W4–12 (45 ч)
**Вход:** P5, S8 (пояснение); (фон: B2 — контекст); B4 (част. с W39+).
**Слоты:** Пн-3, Сб-4
**Теория (14 ч):** 1) тема-1 2) тема-2
**Практика:** 1) шаг 2) шаг
**Гейт (сб 09.01.2027):** ☐ пункт ☐ пункт
**Число:** ≥64 задач
**Файлы:** `folder/note`
**Источники:** Книга гл.1–3
```

Правила:
- `CODE` — `Буквы+цифры(.цифра)?`: `P2`, `S13`, `B9.1`, `CPP4`. Префикс → поток.
- Недели `W4–12` (дефис/en-dash); блок в двух главах = спилл-овер, недели
  объединяются, тело — из первого вхождения.
- **«Вход:»** делится на `;`-сегменты; сегмент с `фон`/`параллельн` → мягкий
  (не рисуется), с `част` (+`WN+`) → пунктирное ребро, остальное — жёсткое ребро.
  Хвост после слова «Выход» игнорируется. Маркеры действуют на весь сегмент:
  частичный вход — отдельным сегментом.
- `☐` в любом label → чекбокс; id детерминированы порядком глав — не менять
  порядок файлов после того, как пользователь начал отмечать прогресс.
- Служебные секции без `CODE ·` (например «Буфер A») игнорируются.

## roadmap.json (минимум)

```json
{
  "start_date": "2026-11-01", "total_weeks": 26, "quarters_weeks": 13,
  "chapters": [{"file": "01_plan.md", "title": "Этап 1"}],
  "streams": {"A": {"label": "Ядро", "color": "#1a365d"}},
  "code_to_stream": {"exact": {}, "prefix": {"A": "A"}}
}
```

Ключи (все кроме chapters опциональны): `buffer_weeks` (дефолт — концы
кварталов), `rates` (ч/нед для бюджета), `total_hours`, `alias` (нестандартный
заголовок → код), `name_overrides`, `expected` (канон — валидатор V6),
`completed_codes` (не проверять заезд), `max_hours_per_week` (32),
`page_title`, `subtitle`, `base_dir` (глава выше конфига).

## Сборка

```bash
cd ~/rofls/boardgen
python3 -m boardgen check --config <путь>/roadmap.json   # валидация
python3 -m boardgen build --config <путь>/roadmap.json --output out.html
# без конфига: python3 -m boardgen build --input a.md --input b.md
```

Валидатор падает адресно: V1 опечатки/висячие входы · V2 циклы · V3 дыры
потоков (каждый поток непрерывен W1..total_weeks) · V4 заезды входов ·
V5 часы >32/нед · V6 канон · V7 статические ✅.

## Порядок работы с пользователем

1. Собрать потокы (3–6) и горизонт в неделях (кратен кварталам по 13 нед).
2. Раскидать блоки по потокам так, чтобы каждый поток покрывал все недели
   без дыр (V3 — самое частое нарушение).
3. Проставить «Вход:» — только жёсткие пререквизиты; мягкие через `(фон:)`.
4. Написать roadmap.json, прогнать `check`, добить ошибки, `build`.
5. Открыть HTML в браузере; прогресс хранится в localStorage.
