# AGENTS.md — контекст для AI-агентов, работающих с boardgen

## Что это

Standalone-генератор интерактивных HTML-досок из markdown-роадмапов.
Python 3.12, stdlib-only, выход — одиночный HTML. История: выделен из личного
проекта-роадмапа (12.10.2026); первый прод-потребитель — 78-недельный роадмап
на 5 потоков / 79 блоков (подключается своим `roadmap.json` + тонкой
CLI-обёрткой `gen.py`).

## Инварианты (нарушение = ломает пользователей)

1. **Порядок глав ↔ id чекбоксов**: `ck-{CODE}-{n}` со сквозным счётчиком.
   Переупорядочивание файлов глав в roadmap.json инвалидирует localStorage
   всех, кто уже отмечал прогресс.
2. **localStorage-ключ** — из конфига (`ls_key`; у прод-доски исторический),
   формат `S` — только additive
   (новые ключи ок, переименование старых — нет).
3. **Байт-детерминизм**: одна и та же пара (карточки+конфиг) → идентичный HTML.
4. **Валидатор до записи**: ошибки → файл НЕ перезаписывается.
5. **JS-инварианты после META-рефакторинга**: в board.js нет литералов
   недель/кварталов/даты старта/потоков и нет захардкоженного localStorage-ключа —
   только `META.*` (`LS/TW/QWn/NQ/BUFW/ST/SL/SC/START`); фоллбеки согласованы
   с дефолтами config.py.

## Рабочие процессы

- Правка ядра: `python3 -m unittest discover tests` + `ruff check .` + смоук
  `examples/mini` + пересборка прод-доски через её обёртку (структурная сверка:
  узлы/рёбра/чекбоксы/частичные рёбра — эталон последней рабочей сборки).
- Новая фича канвасы: править `assets/board.js` напрямую (это файл, не шаблон;
  никаких `{{}}`), при новых данных — маркер в page.html + render.py.
- Правка формата карточек: SPEC.md — источник истины; синхронно обновить
  skills (repo + 3 установки: `~/.config/opencode/skill/boardgen-roadmap/`,
  `~/.claude/skills/boardgen-roadmap/`, `~/.codex/prompts/boardgen-roadmap.md`).

## Известные ловушки

- Замены по подстроке в этом коде уже дважды рвали отступы — правки делать
  по якорям с assert, не «глобально заменить».
- Спилл-овер: тело карточки берётся из первого вхождения; ВХОД тоже. Второй
  файл — только недели.
- Токены «формы кода» (например `B99`) в жёстких сегментах = ошибка V1;
  `RK4` — в `_STOP` (ложное срабатывание).
- `tests` используют `base_dir`-фикстуры и tmp-каталоги: реальные карточки
  пользователей не трогать.
